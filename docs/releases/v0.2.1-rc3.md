# 桌面版无依赖一键部署器 v0.2.1-rc3（build 26102403）

本版本把原来的 C++ 控制台部署器替换为 **C++ 桌面应用一键部署器**，并更新整个软件的版本号为
**v0.2.1-rc3（build 26102403）**。

## 新增 / 变更

- **桌面版部署器（单文件、无运行时依赖）**：GLFW + Dear ImGui + miniz 全部静态编译；启动后在
  「本地版 / 服务器版」之间选择，向导完成下载 → SHA-256 校验 → 解压 → 写配置 → 启动/注册服务 →
  健康检查。
- **Apple 风格 UI + 轻量毛玻璃**：浅色玻璃卡片、圆角、柔和阴影；Windows 11 使用 Mica/Acrylic
  系统级背景材质，macOS 使用 `NSVisualEffectView`，Linux 使用透明窗口 + 玻璃光效；系统中文字体。
- **覆盖平台（部署器本体）**：Windows 10/11 x64/x86/arm64；Debian/RHEL 系与银河麒麟 x64/x86/arm64；
  macOS Apple Silicon。每个平台一个单文件，见本 Release 附件。
- **应用运行时包**：Node.js 24 + 已构建前端 + 生产依赖，提供 5 个平台/架构 zip；
  离线部署时可把 zip 放在部署器同目录或手动选择。
- **README 顶部徽章**：版本、构建号、测试、许可证、安全、平台、部署器、版本形态、Node 版本、
  “powered by dsh”徽章。
- 旧 C++ 控制台部署器（`campus-deploy.exe` / 浏览器控制台 / Cloudflare 隧道交互菜单）移除。

## 下载

部署器（单文件，无需安装）：

- Windows：`mes-deployer-windows-x64.exe`、`mes-deployer-windows-x86.exe`、`mes-deployer-windows-arm64.exe`
- Linux（glibc ≥ 2.31）：`mes-deployer-linux-x64`、`mes-deployer-linux-x86`、`mes-deployer-linux-arm64`
- macOS（Apple Silicon）：`mes-deployer-macos-arm64`

应用运行时包（部署器自动下载，也可离线使用）：

- `mes-homework-app-windows-x64.zip` / `-windows-arm64` / `-linux-x64` / `-linux-arm64` / `-macos-arm64`
- `mes-homework-app-manifest.json`（版本与 SHA-256 清单）
- `SHA256SUMS.txt`（全部资产校验值）

## 已知限制

- 官方 Node.js 24 不提供 32 位运行时：x86 系统上部署器可运行与配置，但应用运行需要 64 位设备/服务器。
- Linux 部署器构建目标为 glibc ≥ 2.31（Debian 11+ / Ubuntu 20.04+ / RHEL 9+ / Kylin V10 SP2+）。
- macOS 仅提供 Apple Silicon 构建；Intel Mac 可用源码构建或 Rosetta。
- 服务器版系统服务安装需要管理员/root 授权；生产模式（Secure Cookie）需外层 HTTPS 反向代理。
- 真实 GUI 交互、各发行版系统服务与真实 HTTPS 下载仍需在目标 OS 手工验收；CI 覆盖构建与核心自检。
